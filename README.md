# xuui skills

Agent skills for [xuui](https://xuui.com), a local canvas for presenting, comparing and reviewing the UIs your coding agents build.

```sh
npx skills add getxuui/skills
```

| Skill | What it does |
| --- | --- |
| [`present`](skills/present/SKILL.md) | Presents the work in the current conversation as a runnable xuui study with reviewable variants, and hands back a local review link. |

Requires Node 24 or newer. See the [agent guide](https://xuui.com/agents.md) for setup and the MCP connection.
